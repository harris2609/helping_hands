# helping_hands

Landing page for Healing Hands Foundation, a government-approved de-addiction and rehabilitation centre in Koduvai, Tiruppur.

Plain HTML, CSS and JS. No build step.

## Run locally

```bash
python3 -m http.server 4321
```

Then open http://localhost:4321.

## Before launch

- Replace `https://example.org` with the real domain in `index.html`, `sitemap.xml` and `robots.txt`.
- Resolve the `TODO` comments in `index.html` (WhatsApp number, Google Maps link, social links, treatment steps).
